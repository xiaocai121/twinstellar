Twinstellar 收款码图片放置处 / Gift QR images go here

请把以下三张图片放进本目录（文件名必须一致，否则弹窗显示为空）：

1. wechat_qr.png  —— 你的个人微信收款码
   （手机微信 → 我 → 服务 → 收付款 → 二维码收款 → 保存收款码图片）

2. alipay_qr.png  —— 你的个人支付宝收款码
   （手机支付宝 → 收钱 → 保存图片）

3. usdt_qr.png    —— 你的 USDT 收款二维码
   （钱包 App → 接收 → 选 TRC20 → 出示二维码截图；地址同时填进 index.html 的 GIFT.usdtAddr）

同时，打开 index.html，把 GIFT.usdtAddr 的占位文字改成你真实的 USDT 钱包地址（TRC20）。

三个通道都就绪后，访客点「解锁深度解读」即弹出本弹窗，扫码付款后点「我已完成礼物」即可解锁。
